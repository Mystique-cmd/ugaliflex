# UPL Lexer (Ugali Preparation Language): JFlex Scanner

A lexical analyzer for the Ugali Preparation Language, built with JFlex and Java. Build instructions are provided for Linux and Windows.

## Project structure

```
project/
├── README.md
└── lexer/
    ├── UgaliLexer.flex     # JFlex specification (edit this)
    ├── UgaliLexer.java     # GENERATED by JFlex (do not edit by hand)
    ├── Main.java           # test driver
    ├── sample.upl          # valid test input
    ├── bad.upl             # input with lexical errors
    └── tokens/
        ├── Token.java
        └── TokenType.java
```

## Linux instructions

Run all commands from the project root (the folder containing `lexer/`).

### Install Java and JFlex

On Ubuntu or Debian, install a JDK and JFlex with:

```
sudo apt update
sudo apt install default-jdk jflex
```

Other Linux distributions provide these packages through their package managers. Install a Java JDK version 17 or newer and JFlex, then verify Java is available:

```
java -version
javac -version
jflex --version
```

### Generate, compile, and run

Generate the scanner from the JFlex specification:

```
jflex lexer/UgaliLexer.flex
```

Compile the Java sources:

```
javac lexer/tokens/*.java lexer/*.java
```

Run the scanner:

```
java lexer.Main lexer/sample.upl
```

Re-run the generation and compile steps whenever `lexer/UgaliLexer.flex` changes.

## Windows instructions

### 1. Prerequisites

#### Java JDK (version 17 or newer)

Check if it is installed. Open a terminal and run:

```
java -version
javac -version
```

Both commands must print a version number. If `javac` is not recognized, you have a JRE only, or the JDK is not on your PATH.

**Install:**
- Run `winget install EclipseAdoptium.Temurin.21.JDK` in PowerShell, or
- Download a JDK from https://adoptium.net. In the installer, enable **"Add to PATH"** and **"Set JAVA_HOME"**.

After installing, **close and reopen your terminal and VS Code.**

**If the JDK is installed but not on PATH** (for example in `C:\Program Files\Java\jdk-25`):

1. Press the Windows key, type **environment variables**, open **Edit the system environment variables**.
2. Click **Environment Variables**.
3. Under **System variables**, select **Path**, click **Edit**.
4. Click **New** and add `C:\Program Files\Java\jdk-25\bin` (use your real JDK folder).
5. Use **Move Up** to put it at the top, then click OK on every window.
6. Close and reopen VS Code and any terminals.

Always use **New** to add a line. Never replace the existing text.

#### JFlex (version 1.9.1)

1. Download the zip from https://jflex.de.
2. Unzip it somewhere simple, for example `C:\Users\<you>\jflex-1.9.1`.
3. You do **not** need to add JFlex to PATH. Call it by its full path (see below).

#### VS Code (optional)

Install the **Extension Pack for Java** (Microsoft) for editing. The build works from any terminal.

### 2. Build and run

Run all commands **from the project root** (the folder that contains `lexer/`), not from inside `lexer/`. In VS Code, open the project folder and use the built-in terminal (`` Ctrl+` ``), which starts in the right place.

### Step 1: Generate the scanner

PowerShell:
```
& "C:\Users\<you>\jflex-1.9.1\bin\jflex.bat" lexer/UgaliLexer.flex
```

Command Prompt:
```
"C:\Users\<you>\jflex-1.9.1\bin\jflex.bat" lexer\UgaliLexer.flex
```

Replace `<you>` with your Windows username, or use wherever you unzipped JFlex. This creates `lexer/UgaliLexer.java`.

### Step 2: Compile

```
javac lexer/tokens/*.java lexer/*.java
```

If the wildcards cause trouble, list the files explicitly:
```
javac lexer/tokens/Token.java lexer/tokens/TokenType.java lexer/UgaliLexer.java lexer/Main.java
```

### Step 3: Run the scanner

```
java lexer.Main lexer/sample.upl
```

Use `lexer.Main` (the package name), not `Main`.

**Re-run Steps 1 to 3 every time you change `UgaliLexer.flex`.**

### 3. Expected output

For an input file containing `boil 4 cups water;`:

```
BOIL
NUMBER(4)
CUPS
WATER
SEMICOLON
```

For input with illegal characters, errors are printed and scanning continues:

```
Lexical error at line 3, column 5: illegal character '@'
```

To see errors and tokens in order in one stream:

```
java lexer.Main lexer/bad.upl 2>&1
```

### 4. Troubleshooting

| Problem | Fix |
|---|---|
| `java` or `javac` is not recognized | The JDK `bin` folder is not on PATH. Add it (see section 1), then reopen the terminal and VS Code. |
| `java` works but `javac` does not | Another Java is earlier in PATH. Run `where.exe javac` and `where.exe java`, and move the JDK `bin` entry to the top of PATH. |
| Temporary fix in PowerShell | `$env:Path = "C:\Program Files\Java\jdk-25\bin;" + $env:Path` |
| Temporary fix in Command Prompt | `set "PATH=C:\Program Files\Java\jdk-25\bin;%PATH%"` |
| `$env:Path` gives a syntax error | You are in Command Prompt, not PowerShell. Use the `set` version, or type `powershell` first. |
| Pasted command fails with "unexpected token" | You pasted the prompt text (`C:\Users\...>`) or old output with it. Paste only the command. |
| PATH entries disappear | You used `=` instead of `+=` in PowerShell. Use `+=` or the Environment Variables window's **New** button. |
| Red error on `UgaliLexer` in VS Code | The class doesn't exist until JFlex runs. Do Step 1. |
| `cannot find symbol: Token` | Check the `package` and `import` lines in every file, and that the `tokens` folder matches `lexer.tokens`. |
| `Could not find or load main class` | Run from the project root and use `java lexer.Main`. |
| Everything is printed as `ID` | Keyword rules must come before the `{ID}` rule in the `.flex` file. |
